## 安装依赖
项目使用 Python 3.12

```bash
conda create -n your_env_name python=3.12 pip
conda activate your_env_name
python -m pip install -r requirements.txt
```

## 运行作业
在项目根目录执行以下命令以运行实验

```bash
python Question1/question1.py
python Question2/question2.py
```
